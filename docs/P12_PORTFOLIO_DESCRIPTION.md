# Portfolio Project Description — LifePilot AI

## Short version

**LifePilot AI — Privacy-Aware Personal Operations Platform**  
Built a full-stack Laravel + React platform that turns private life records into an organized evidence graph for documents, tasks, finances, subscriptions, assets, warranties and calendar events. Added grounded RAG with citation validation, explainable analytics, shared-household privacy controls, and safe agentic workflows where AI can propose actions but high-impact execution requires explicit user approval.

## CV version

- Engineered a Laravel 12 + React/TypeScript personal operations platform covering secure document management, OCR/extraction review, task/obligation automation, finance, subscriptions, assets, warranties, calendar, notifications and household collaboration.
- Built sharing-aware semantic/RAG retrieval with evidence citations and hallucination guards that reject unsupported amounts, deadlines and inaccessible private records.
- Implemented safe agentic action planning with policy/evidence validation, risk classification, explicit approval, idempotent execution, rollback and audit trails; financial transaction execution is intentionally excluded.
- Added interpretable forecasting and analytics using moving averages, exponential smoothing and transparent logistic-style risk scoring, with persisted model/feature versions, confidence and explanations.
- Added production-readiness evaluation, security review, four-variant comparison and PDF/CSV/JSON reporting without fabricating metrics when labeled ground truth is unavailable.

## Interview framing

LifePilot is designed around a strict rule: **AI is an assistive layer, not the source of truth.** Core CRUD, reminders, scheduling and finance workflows work without AI. Uploaded documents remain evidence, household sharing is explicit, assistant answers are grounded and cited, and actions are previewed before execution. This makes the project a practical demonstration of full-stack engineering, API security, RAG safety, explainable AI, event-driven workflows, authorization design and evaluation discipline.
